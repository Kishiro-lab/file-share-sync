ファイル共有と同期 プライバシーポリシー

制定日: 2026年10月28日

「ファイル共有と同期」は、下に挙げる個人用のアプリ(以下「本アプリ」)が、利用者自身のGoogleドライブを使って 端末どうしでデータを受け渡したり、仲間とファイルを共有したりするためのGoogleログインです。 本アプリが扱う情報と、その扱い方を次のとおり定めます。

対象のアプリとGoogleドライブで扱うもの

アプリGoogleドライブで読み書きするもの
ToDoボード
(Windows版・Android版)		 マイドライブの「ToDoボード同期」フォルダにある同期用ファイルと添付ファイルの写し。
PDF Tools
(Windows版)		 マイドライブの「PDF Tools 共有プロジェクト」フォルダに作った共有プロジェクト(.pdftools)と、 ほかの利用者から共有された共有プロジェクト。共有するときは、利用者が入力した相手のメールアドレスへ、 そのファイルの編集権限を与えます(Googleから相手へ知らせのメールが届きます)。
現地プロット
(Android版・Windows版)		 マイドライブの「現地プロット同期」フォルダにある現場ごとの同期用ファイルと写真・図面の写し。

本アプリは、上に挙げたもの以外のファイルを読んだり、変更したり、削除したりしません。

ドライブ全体への権限を求めるのは、Google Drive for desktop で作られた同期フォルダや、 ほかの利用者から共有されたファイルを、本アプリから開けるようにするためです。

扱う情報

本アプリが扱うのは、利用者が本アプリに入力した内容(カード・現場・書き込みなど)と、 共有の相手として利用者が入力したメールアドレス、ログインしたGoogleアカウントのメールアドレス(画面に表示するため)だけです。 これらは利用者の端末と、利用者自身のGoogleドライブに保存されます。

外部への送信

本アプリは、利用者のデータを開発者のサーバーやその他の第三者へ送信しません。広告や利用状況の分析も行いません。 データが端末の外へ出るのは、利用者自身のGoogleドライブとのやり取りと、利用者が共有を指示した相手への共有だけです。

Google API サービスのユーザーデータに関するポリシー

本アプリがGoogle APIから受け取った情報の使用および他のアプリへの転送は、 Google API Services User Data Policy(Limited Use の要件を含む)に従います。

権限の取り消しとデータの削除

本アプリへのGoogleドライブの権限は、Googleアカウントのサードパーティ アクセスからいつでも取り消せます。 端末内のデータは本アプリを削除すると消えます。Googleドライブ上のデータは、上の表のフォルダやファイルを削除すると消えます。 共有したファイルは、Googleドライブで共有を外すと相手から見えなくなります。

改定

このポリシーを変更するときは、このページを更新します。
